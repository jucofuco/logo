# Mulberry Symbols

The files in `svg/` are symbols from the **Mulberry Symbols** set by Steve Lee,
https://mulberrysymbols.org, copied unchanged from the official release (version in `VERSION.txt`).

License: **Creative Commons Attribution-ShareAlike 4.0** (https://creativecommons.org/licenses/by-sa/4.0/),
text in `LICENSE.txt`.

- The app shows this credit in Settings when the Mulberry set is picked. Keep it there.
- The symbols (and changes to them) stay under CC BY-SA 4.0. That covers the pictures, not the app code.
- The website says the symbols themselves must not be sold. Check this before charging for the app.
- Which Mulberry symbol stands for which word is in `import_mulberry.py` (`MAPPING`).
